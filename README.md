# 🎃 Survival Horror Portfolio

Portfolio personal con estética inspirada en videojuegos y películas de horror como *Resident Evil*, con efectos visuales de glitch, tipografías retro, sonido, animaciones y mucho estilo.

## 💼 Tecnologías principales

- **React** + **Vite**
- **Tailwind CSS** con extensiones personalizadas
- **Lucide‑React y React-Icons** (íconos)
- **react‑parallax‑tilt**: efectos 3D tilt en cards
- **@splidejs/react-splide**: carrusel de proyectos
- **Typewriter effect**: texto animado
- **MP3 personalizados** para themes y eventos
- **CSS/glitch animations** para efectos visuales
- **spoiled**: efecto para ocultar información

## 🎨 Estilo visual
- Paleta de colores y estilos basado en los remakes del videojuego Resident Evil.
- Tipografía horror 
- Fondo con ruido animado (grain).
- Cursor personalizado, transiciones VHS, parpadeos.
- Efecto de distorsión sonora al cambiar theme.

## ⚙️ Funcionalidades

| Función | Descripción |

| Toggle tema | Cambio claro/oscuro con sonido |
| Fondos animados | Noise/grano tipo analógico |
| Hero section | Texto tipeado estilo Typewriter animado |
| Carrusel de proyectos | Responsive, con efecto tilt 3D en cada card |
| Cursor con partículas |
| Responsive | Diseño optimizado para desktop y mobile |
